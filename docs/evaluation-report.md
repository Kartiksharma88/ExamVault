## Observations & Analysis
1. **Constraint Satisfaction:** The CP-SAT solver achieved 100% topic compliance across all 200 papers, whereas random selection failed in over 60% of cases due to unguided topic selection.
2. **Difficulty Control:** The CP-SAT solver tightly centered the papers around the target difficulty (mean deviation 0.01 vs 3.65 for random).
3. **Anti-Leakage Overlap Control:** Consecutive papers generated by CP-SAT never shared more than 3 questions, strictly observing the overlap limit. Random selection suffered from multiple consecutive overlap spikes up to 3 questions.
4. **Performance:** The CP-SAT solver solved all 15-question optimization problems with a p95 latency under 1848.88 ms (well below the 5.0s requirement).
